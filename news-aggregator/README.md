# Google News Clone — Zero-Firewall News Aggregator

A Google News-style single-page news aggregation site hosted on **GitHub Pages**. It uses a **Mock-driven development + CI pre-fetching** architecture so the entire project can be developed offline and then deployed with real news fetched by GitHub Actions.

---

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│  Development (Agent machine, no external network)            │
│  ┌─────────────┐    ┌─────────────┐                        │
│  │ React + Vite│ ← │ Mock JSON   │  100% offline dev/test  │
│  │ Tailwind CSS│    │ (mock-news) │                        │
│  └─────────────┘    └─────────────┘                        │
└─────────────────────────────────────────────────────────────┘
                              ↓ push to GitHub
┌─────────────────────────────────────────────────────────────┐
│  Build & Deploy (GitHub Actions, external network allowed)   │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐     │
│  │ fetch-news  │ → │ Parse RSS   │ → │ news.json   │     │
│  │ (Node.js)   │    │ (Google)    │    │ (static)    │     │
│  └─────────────┘    └─────────────┘    └─────────────┘     │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐     │
│  │ npm run     │ → │ dist/       │ → │ GitHub      │     │
│  │ build       │    │ (static)    │    │ Pages       │     │
│  └─────────────┘    └─────────────┘    └─────────────┘     │
│  Trigger: every 2 hours / on push / manual                   │
└─────────────────────────────────────────────────────────────┘
                              ↓ user visits
┌─────────────────────────────────────────────────────────────┐
│  User browser (any country)                                  │
│  Reads same-origin /data/news.json — no CORS, no API keys   │
└─────────────────────────────────────────────────────────────┘
```

## Tech Stack

- **Framework:** React 18 + TypeScript + Vite 5
- **Styling:** Tailwind CSS 3
- **Icons:** Lucide React
- **Build output:** Static `dist/` directory for GitHub Pages
- **Routing:** None — single-page category switching via React state
- **Build-time script:** Node.js + `fast-xml-parser` for RSS parsing
- **Weather:** Open-Meteo API (free, no API key, called from browser)

## Local Development

```bash
cd news-aggregator
npm install
npm run dev
```

The development server uses `.env.development`, so `VITE_USE_MOCK=true` and the app reads `/data/mock-news.json`. No external network requests are made.

---

## Build for Production

```bash
npm run build
```

This compiles TypeScript and produces a static `dist/` folder. In production mode the app will fetch `/data/news.json` (generated by GitHub Actions).

---

## Generate Mock Data JSON

```bash
npx tsx scripts/generate-mock-json.ts
```

This writes `public/data/mock-news.json` from `src/data/mockNews.ts`.

## Deployment to GitHub Pages

1. **Create a GitHub repository** and push this project.
2. **Enable GitHub Pages:**
   - Go to **Settings → Pages**.
   - Under **Build and deployment → Source**, select **GitHub Actions**.
3. The workflow `.github/workflows/deploy.yml` runs automatically on every push to `main` and every 2 hours via `schedule`.
4. **(Optional) Trigger manually:**
   - Go to **Actions → Fetch News & Deploy to GitHub Pages → Run workflow**.
   - Wait 2–3 minutes for the site to update.

## Data Sources

- **News:** Google News RSS feeds (no API key required).
- **Weather:** Open-Meteo forecast API + browser Geolocation (fallback to Beijing).
- **Favicons:** Google S2 favicon service (`https://www.google.com/s2/favicons?domain=...`).

## Why This Works Without a Firewall

| Problem | Traditional approach | This project |
|---|---|---|
| Agent cannot reach Google News | Direct API calls fail | 100% mock data during development |
| Data freshness | Static content never updates | GitHub Actions fetches RSS every 2 hours |
| API costs / limits | NewsAPI quotas | Free Google News RSS |
| User browser blocked | Client calls foreign APIs | Reads same-origin static JSON |
| CORS issues | Browser blocks cross-origin | No cross-origin data requests |
